# Pong Game

A classic Pong game built with HTML5, CSS3, and vanilla JavaScript. Play against a computer AI opponent in this retro arcade game.

## Features

✨ **Game Features:**
- 🎮 Mouse and keyboard controls for the left paddle
- 🤖 AI-controlled computer opponent for the right paddle
- ⚽ Physics-based ball movement with wall and paddle collision detection
- 📊 Real-time scoreboard tracking player and computer scores
- 🎨 Modern UI with glowing effects and smooth animations
- 📱 Responsive design that works on different screen sizes
- 🔄 Reset button to start a new game

## How to Play

1. **Open the game:** Open `index.html` in your web browser
2. **Move your paddle:**
   - Use your **mouse** Y-position to control the left paddle, OR
   - Use **Arrow Up** and **Arrow Down** keys to move the paddle
3. **Beat the computer:** Score by getting the ball past the computer's paddle
4. **Computer opponent:** The AI-controlled right paddle will try to block your shots

## Game Controls

| Action | Control |
|--------|---------|
| Move Paddle Up | ⬆️ Arrow Up or 🖱️ Move Mouse Up |
| Move Paddle Down | ⬇️ Arrow Down or 🖱️ Move Mouse Down |
| Reset Score | 🔄 Click "Reset Game" Button |

## Game Mechanics

- **Ball Physics:** The ball bounces off walls and paddles with realistic physics
- **Paddle Spin:** The ball's angle changes depending on where it hits the paddle
- **Score System:** Points are awarded when the ball passes the opponent's paddle
- **AI Difficulty:** The computer has slight reaction delays to make it beatable
